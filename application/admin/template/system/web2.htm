系统运行模式
 

开发模式：适合开发和调试阶段。修改模板后立即生效，无需清除缓存，方便实时预览效果。
运营模式：适合正式运营阶段。启用缓存提升网站访问速度，有利SEO收录。修改模板、采集或导入文档后，需执行【更新缓存】才能在前台看到效果。

开启后，sitemap.xml地图以及全站URL将强制使用HTTPS协议访问。

 

开启后，删除的文档、栏目等内容将进入回收站，可以恢复。关闭后，删除的内容将直接永久删除，无法恢复。

 

开启后，在静态页面模式下，系统会在PC端模板的head标签中自动添加跳转代码。当用户使用手机访问PC端URL时，将自动跳转到对应的手机端页面。

 

开启后，在发布/编辑文档的页面会出现选择副栏目，实现文档的多栏目分类。
注意：此功能会增加系统负载，建议在文档量较大时谨慎开启。

 

开启后，系统中的附件、图片、栏目链接、文档链接等将使用完整的绝对网址（包含域名）。
适用于：内容需要被其他网站引用、RSS订阅、邮件发送等场景。
关闭时使用相对路径，适合单域名网站。

如果EyouCms安装在网站子目录中，请在此填写子目录名称（不含域名，不含前后斜杠）。例如：如果访问地址是 http://www.example.com/cms/，则填写 cms。如果安装在根目录，请留空。

 如何防止模板被仿盗？

如果当前使用的是静态URL模式，切换模板风格后请重新生成所有静态页面，否则前台可能显示异常。
